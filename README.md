WindChat Мессенджер на Python с использованием фреймворка Flask
• Реализовано динамическое обновление данных через SSE поток
• 3 модели (Chats, Users, Messages)
• REST API (для Chats, Users и Messages)
• Базовые шаблоны (auth-base.html и base.html)
• 5 шаблонов
• 3 формы
• Скрипт для работы с API на JavaScript
• Стилизация при помощи CSS
